# Citizen Guilds
Mod Minecraft Java 1.21.1 / NeoForge 21.1.215 / Java 21 pour CITIZEN.

## Fonctionnalités prévues
- création et gestion des guildes ;
- invitations, membres, grades et permissions ;
- banque/inventaire partagé ;
- dépôt automatique des Pierres de Jade obtenues en donjon ;
- journal des dépôts et retraits ;
- activités, donjons, boss et contributions ;
- emblème et bannière personnalisables.

## État actuel
Une première base visuelle est présente. La fenêtre s'ouvre avec la touche **G** et affiche les onglets Vue d'ensemble, Membres, Banque, Activités et Journal.
**Prototype uniquement :** les actions de gestion et les données serveur ne sont pas encore implémentées. Ne pas utiliser en production.

## Compilation
JDK 21 requis. Lancer `gradle build`. Le JAR sera généré dans `build/libs/`.
